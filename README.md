# Princess Erika Mahinay — Virtual Assistant Portfolio

A static portfolio ready for GitHub Pages. The website files are at the repository root, including `index.html` and the interactive fictional real estate CRM example.

## Publish with GitHub Pages

1. Create a public repository named `<your-github-username>.github.io` for a clean address such as `https://your-github-username.github.io/`.
2. Upload all files from this folder to the repository root on the `main` branch.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)` and save.
4. GitHub will show the published address in **Settings → Pages** after deployment.

The portfolio uses relative links, so the same files also work in a normal project repository at `https://your-github-username.github.io/repository-name/`. The CRM demo contains fictional data and changes made there stay only in the browser tab.
